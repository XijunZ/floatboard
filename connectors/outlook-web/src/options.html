FloatBoard for Outlook

Reads the unread emails your Outlook inbox shows in Chrome and sends them to your FloatBoard engine. It only reads what is on screen without scrolling, usually the newest 20 to 50 emails, and never changes anything in Outlook.

Connection

From the Outlook section of your engine's setup page. Kept only on this computer.

Page sample

Saves a copy of the open Outlook page with every name, address, id and message text replaced by placeholders, so the page layout can be checked without sharing your email.
